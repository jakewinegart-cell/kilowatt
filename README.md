# Kilowatt (kw2)

A phone-first, private cost tracker for your lights. Plain HTML/CSS/JS, no build step, no backend, no tracking — data lives in your browser's localStorage.

Live: https://jakewinegart-cell.github.io/kilowatt/

State average residential rates: U.S. EIA, Electric Power Monthly, Table 5.6.A (August 2026 data).

## kw2 — bulb photos
Bulb-type picker shows photos of common bulbs (`img/`, 240×240 WebP, ~50 KB total), from Wikimedia Commons under CC BY / CC BY-SA / CC0 licenses. Full per-image credits (author, license, source link) are in `bulbs.js` and in the app's footer under "Photo credits".
